A Station view over any StationSpec, without the CMS cache (T-030).

set_cell_attrs(dt_info)[source]

Set the attributes for the drift cells in the station.

Parameters:

dt_info (dict, list, or pandas.DataFrame) – Drift cell information for the station. Can be a dictionary, a list of dictionaries, or a pandas DataFrame containing the drift cell attributes, they should be identified by super layer, layer, and cell. e.g. [{“sl”: 1, “l”: 1, “w”: 1, “time”: 300}, …]

Note

This writes on this station’s own cells. On a station shared through StationsCache use overlay() instead: the cache hands the same instance to every caller.

overlay(dt_info=None)[source]

A per-event view of this station: the same geometry, its own cell attributes.

The node tree and the frame graph are shared with this station, so an overlay costs a fraction of a full build; the super layers, layers and cells are new objects, so setting an attribute on an overlay cell never reaches the station or another overlay.

Parameters:

dt_info (dict, list of dict, or pandas.DataFrame, optional) – Drift cell information, as in set_cell_attrs().
