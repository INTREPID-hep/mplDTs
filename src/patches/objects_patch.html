DTObjectsPatch

DTObjectsPatch draws arbitrary points and polylines of a chamber: hits, tracks, showers, trigger primitives. Every object is given in any frame the station graph resolves (Station, CMS, SL2, a cell…) and lands on the grid the cells use, so the local/global and inverted views come from the same place as in DTStationPatch.

objects is an iterable of (points, style) pairs: points is an (N, 3) array in frame and style the keyword arguments of one matplotlib.lines.Line2D. One point is a marker (linestyle=”None”), two or more are a polyline; a style given to the constructor applies to every object and each object’s own wins.

from mpldts.geometry import STATION_CACHE
from mpldts.patches import DTObjectsPatch

station = STATION_CACHE.get(0, 1, 1)
hit = (1.0, 2.0, 3.0)                       # Station coordinates

DTObjectsPatch(
    station,
    ax,
    [(hit, {"marker": "*", "linestyle": "None", "color": "tab:red"})],
    faceview="phi",
    local=True,
    inverted=True,
)

Bases: DTRelatedPatch

A collection of points or polylines drawn in the view of a DT chamber.

Attributes:

objectslist

The (points, style) pairs given by the caller.

framestr

The frame the coordinates are expressed in (“Station” by default; any name the station graph resolves, “CMS” included).

axesmatplotlib.axes.Axes

The matplotlib axes to draw the objects on.

viewstr

The view type, either “phi” or “eta”.

localbool

Boolean indicating whether to use local or global coordinates.

invertedbool

Boolean indicating whether to invert the view. If local is False, this will not have any effect.

The style of each object is the keyword arguments of one matplotlib.lines.Line2D: a single point is a marker (linestyle=”None”, marker=”*”), two or more are a polyline.

Important

The coordinates are the ones the cells use: horizontal station x, vertical station z, in both views. A line given in CMS and the same line given in Station land on the same pixels; local=False and inverted=True then move the objects exactly like the cells.

Parameters:

  • station (mpldts.geometry.Station) – The Station object containing the geometry information.

  • axes (matplotlib.axes.Axes) – The matplotlib axes to draw the objects on.

  • objects (iterable of (array-like, dict)) – (points, style) pairs; points is an (N, 3) array in frame and style a dict of Line2D keyword arguments.

  • faceview (str, optional) – The view type, either “phi” or “eta”.

  • local (bool, optional) – Boolean indicating whether to use local or global coordinates.

  • inverted (bool, optional) – Boolean indicating whether to invert the view.

  • frame (str, optional) – The frame the points are expressed in.

  • style – Keyword arguments applied to every object (each object’s own style wins).

Returns:

None. Adds one line artist per object to the axes.

_to_face(points)[source]

The coordinates the cells are drawn at: (station x, station z).

The two views differ in which super layers they show, not in the pair of axes: #BT#DTStationPatch#BT# draws every cell at its station x and z, so an object has to land on those numbers or it does not sit on its cell. The view still drives the local/global and inverted transforms above.
