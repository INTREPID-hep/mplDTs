## What was done

1. **Corrected the model concepts** after review:
   - Cell = XML `<Wire>` entry; CellGrid repeats cells (no separate wire object).
   - The XML `<Wire>` element is the cell entry (number + position).
   - Shapes are not only boxes: `Box` and `Tube`; the tube-cell case is
     supported.
2. **Specified the transformation design**:
   - one `Pose` per node (child → parent, cm);
   - `FrameGraph` (shared, path ids, BFS + cache) + `FrameView` (scoped aliases
     and virtual frames, preserving the `transformer` API);
   - top-down `world_pose` in the builder, no per-cell `TransformManager`.
3. **Deferred pyg4ometry** but left the seam:
   - `VolumeSink` protocol, `RecordingSink`, `export_volumes`;
   - backend-neutral `Shape` (`aabb`, `volume`, `symmetry_axis`);
   - G4 z→y alignment adapter (`g4_alignment`) outside the shape;
   - future `mpldts/export/pyg4ometry.py` is additive.
4. **Prototype v2** (`prototype/parametric_poc.py`):
   - box station (CMS-like 49/50/49/48, stagger) and tube station in one graph;
   - frame graph, aliases, virtual frame, JSON, exporter folding, sink;
   - all checks 0.0; 193 placements; box/tube volumes.
5. **Design document Rev 2** (`docs/design/generalization-plan.md`); v1
   archived.
6. **`.agents` workspace** created: AGENT, context, state, plan, tasks,
   conventions, decisions, commands, glossary, handoff, templates, log.
